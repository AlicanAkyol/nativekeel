Privacy

Last updated 5 October 2026.

The command-line tool

NativeKeel runs on your machine. It does not upload your source code, reports or secrets anywhere and has no analytics or telemetry. To check versions it sends package names (for example react-native-svg) to the public npm registry and to React Native Directory. For the vulnerability check it sends the names and exact versions of your runtime dependencies to npm's advisory endpoint, the same request npm audit makes. Nothing else is sent. Those services' own privacy policies apply to those requests.

With --offline it makes no network requests at all.

When you contact or buy from us

We keep what you send us by email (name, company, email address, invoices and any report you attach) to answer you, deliver services, and meet accounting obligations. We do not sell it or use it for advertising.

For service work you grant us access to one repository. We use it only for the agreed work and you can revoke it at any time. Your code is kept on an encrypted machine and deleted when the engagement ends; we confirm the deletion in writing.

We use AI coding assistants for service work only under terms that do not allow your code to be used for model training. If your policy forbids AI tools, tell us before work starts and we will not use them on your code.

We never ask for App Store or Google Play passwords, signing keys or production secrets.
