Check your React Native app’s package.json

Paste a React Native or Expo package.json. NativeKeel checks it right here in your browser: unsupported versions, libraries that block the New Architecture or are no longer maintained, major updates, and an upgrade plan in the order to do it.

Your file stays in this tab. The page only asks npm, React Native Directory and unpkg about the package names in it, the same lookups the CLI makes.

Expo app? Add app.json (optional)

What this page does not check

Only what a package.json shows. The full scan also reads your code and native projects: leaked keys, OWASP MASVS security findings, known vulnerabilities in the exact versions you ship, Google Play and App Store settings, crash risks in native files, accessibility, and your release bundle. Run it locally, nothing to install:

npx nativekeel
